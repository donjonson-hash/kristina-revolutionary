# Кристина — офисный помощник 0.3.0

Кнопка расширения открывает сверку в отдельной вкладке. Загрузите два файла:
совместимые столбцы и идентификатор определяются автоматически, а различия
выделяются прямо в содержимом документов. При неоднозначности Кристина просит
уточнить настройки. Доступны HTML-отчёт и JSON с исходными значениями и SHA-256.

## Общение с Кристиной

Панель офисного помощника сопровождает текущую сверку: после загрузки Кристина
объясняет результат, отвечает на вопросы об изменениях и помогает подготовить
письмо. Можно нажать готовый вопрос или написать свой, например:

- «Где изменилась цена?»
- «Что отсутствует во втором файле?»
- «Почему значения одинаковые?»
- «Покажи OFF-008»
- «Подготовь письмо»

Кнопки в ответах открывают соответствующие позиции в документах, в том числе
на следующих страницах. Черновик письма можно отредактировать, скопировать или
скачать как TXT; отправку пользователь выполняет сам.

Эта версия понимает ограниченный набор вопросов по текущей сверке и сообщает,
если вопрос выходит за её возможности. Ответы формируются по данным отчёта,
без LLM и сетевых запросов. Кристина не делает выводов о фактической поставке,
причинах изменений или непроверенных полях. Смена файлов или правил сбрасывает
диалог и черновик. История не сохраняется после закрытия вкладки.

Если установлена предыдущая версия, распакуйте новый архив в отдельную папку.
В Firefox удалите временное дополнение на странице `about:debugging`, затем
загрузите `manifest.json` новой версии. В Chrome удалите прежнее распакованное
расширение и загрузите новую папку. Результаты текущей сверки перед этим можно
сохранить кнопкой «Скачать отчёт».

## Установка для проверки

Сборка из корня репозитория, без установки дополнительных зависимостей:

```bash
python3 scripts/build_reconciliation_extension.py
```

Результат: каталоги `dist/extension/firefox`, `dist/extension/chrome` и два ZIP.
Полученный ZIP можно распаковать на любом компьютере — Python для работы
расширения не требуется.

### Firefox 142 и новее

1. Распакуйте `kristina-firefox-0.3.0.zip`.
2. Откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите «Загрузить временное дополнение» и выберите `manifest.json` в распакованной папке.
4. В меню расширений нажмите «Кристина — офисный помощник».

Это временная установка: после перезапуска Firefox дополнение нужно загрузить
снова. Для постоянной установки в обычном Firefox потребуется подпись Mozilla.
Архив не подписан и не опубликован в магазине.

### Chrome 120 и новее

1. Распакуйте `kristina-chrome-0.3.0.zip`.
2. Откройте `chrome://extensions` и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение», выберите папку с `manifest.json`.
4. Закрепите Кристину в панели расширений и нажмите её кнопку.

## Что поддерживается

- CSV/TSV в UTF-8, включая BOM; запятая, точка с запятой или табуляция.
- XLSX ↔ XLSX и XLSX ↔ CSV/TSV. Единственный заполненный лист выбирается
  автоматически. При нескольких заполненных листах выберите нужный рядом
  с файлом; скрытые листы тоже перечисляются. Проверяется только выбранный лист.
- До 2 MiB, 5 000 записей и 200 столбцов в каждом файле; поле до 131 072 символов.
- Текст сравнивается точно; идентификаторы сохраняют ведущие нули.
- Десятичное сравнение не использует float: `10.00` равно `10`. Текстовые числа
  CSV не теряют точность. Числовые ячейки XLSX читаются в пределах точности Excel;
  длинные артикулы храните как текст. Единицы и валюты не пересчитываются.
- Дубликаты ключей, пустые ключи и некорректные числа требуют уточнения;
  частичный результат не выдаётся за выполненную сверку.
- Отчёты ограничены 16 MiB каждый; обработка прерывается через 40 секунд.

### Как читается Excel

Первая заполненная строка выбранного листа должна содержать непустые уникальные
заголовки. Пустые строки пропускаются, скрытые строки и столбцы включаются.
Отчёт и подсветка сохраняют имя листа, исходный номер строки, адрес каждой ячейки
и SHA-256 исходного XLSX, а не промежуточного CSV.

Сверяются значения. Текст сохраняется точно; простой числовой формат `00000`
сохраняет ведущие нули. Остальные числовые значения показаны без валютного,
процентного и прочего оформления. Даты показаны в ISO (`YYYY-MM-DD`, при наличии
времени — `YYYY-MM-DDTHH:mm:ss`), логические значения — `TRUE`/`FALSE`.
Оформление, изображения, комментарии и порядок строк не сравниваются.

Формулы (включая формулы без сохранённого результата), ошибки Excel и объединённые
ячейки останавливают сверку с пояснением. Подготовьте отдельную копию листа со
значениями и одной строкой заголовков. Формулы не вычисляются и сохранённым
результатам формул не доверяем. Макросы, внешние связи, XLS/XLSM/XLSB/ODS,
PDF, DOCX и вычитка свободного текста пока не поддерживаются.

Дополнительные пределы книги: 100 листов, 100 000 заполненных ячеек,
16 MiB фактически распакованных данных, 1024 ZIP-записи. Проверяются ZIP-структура,
размеры и CRC до разбора книги. Тайм-аут Worker остаётся 40 секунд.

Excel в этой версии доступен в расширении. Локальный Python-интерфейс продолжает
принимать CSV/TSV и явно сообщает об этом при перетаскивании Excel.

## Приватность и устройство

Файлы обрабатываются в Web Worker внутри браузера. Расширение не запрашивает
доступ к сайтам, истории, вкладкам или диску, не использует сервер, LLM,
телеметрию или постоянное хранилище. Вы выбираете файлы обычным файловым диалогом;
отчёт сохраняется только по нажатию кнопки. При закрытии вкладки или её
перезагрузке выбранные данные теряются. CSP запрещает сетевые соединения.

Сборка копирует общий интерфейс `static/reconciliation/`, подключая локальный
`transport.js` вместо HTTP API. Python-интерфейс продолжает использовать HTTP.
Каждая операция получает отдельный Worker; отмена, ошибка и тайм-аут завершают
его. `engine.mjs` повторяет правила Python-движка; `report.mjs` формирует
автономный отчёт с экранированием содержимого.

`xlsx-source.mjs` использует закреплённую локальную копию SheetJS CE 0.20.3
(`xlsx-vendor.mjs`, Apache-2.0, `SHEETJS-LICENSE.txt`). Ничего не загружается из CDN
при работе расширения. Официальный исходник:
https://cdn.sheetjs.com/xlsx-0.20.3/package/xlsx.mjs
SHA-256: `1a0fb062ee9781b13f6687371b202aaefc53b6ce55b530c027e01f9c087b77db`.
Документация: https://docs.sheetjs.com/docs/getting-started/installation/standalone/

## Проверка разработчиком

```bash
npm ci --ignore-scripts --prefix tests/browser
node --test tests/extension/*.test.*
python3 scripts/build_reconciliation_extension.py
```

Тесты проверяют совместимость с Python, обработку CSV, экспорт, упакованные
ресурсы, запуск через Worker и сценарий загрузки/сверки/скачивания в jsdom.
Проверка DOM не заменяет ручную установку в Firefox и Chrome: после установки
нажмите «Попробовать на примере», ожидайте 2 изменённые позиции, по одной только
в A и B и одну совпавшую; скачайте и откройте HTML-отчёт.

Документация платформ:
- https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/
- https://extensionworkshop.com/documentation/develop/firefox-builtin-data-consent/
- https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked

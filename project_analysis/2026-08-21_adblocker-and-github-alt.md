# Анализ идей: Блокировщик рекламы и Альтернатива GitHub

- **Источник:** отчёт TrendScout — блокировщик (Σ = 17) и альтернатива GitHub (Σ = 18)
- **Дата анализа:** 2026-08-21
- **Вердикт:** ❌ обе **отклонить**. Реальная вирусная боль ≠ монетизируемая ниша:
  в обоих случаях лидеры бесплатны/open-source, аудитория идеологически против
  платы, а платформенный рычаг держит гигант (Google в блокировщиках, Microsoft
  в git-хостинге).

---

## Идея A: Блокировщик рекламы нового поколения (Σ 17 → 13)

### Проверка тренда — реален, но уже отыгран
Manifest V3 в 2026 реально урезал блокировщики: `declarativeNetRequest` с лимитом
~30 000 правил против 300 000+ у полного uBlock Origin. Firefox — единственный
крупный браузер с полной поддержкой uBO; в Chrome/Edge только urезанный uBO Lite.
Вирусный пост на HN фиксирует **боль, а не незанятый спрос** — рынок уже
отреагировал миграцией на Firefox/Brave и DNS-уровень.

### Конкуренты — перенасыщено и бесплатно
- Браузер: uBlock Origin (free, OSS), Brave (встроенный), AdGuard (freemium).
- DNS: Pi-hole и AdGuard Home (100% free, OSS), NextDNS и AdGuard DNS (~$14/год).

### Почему плохая ниша
1. **Ценовой якорь = 0** (лидеры бесплатны, потолок платных ~$14/год).
2. **Идеологическая аудитория** — антикоммерческая, склонна к self-host, недоверчива
   к проприетарным продуктам, «видящим весь трафик».
3. **Власть Google** (MV3) + бесплатные Firefox/Brave закрывают браузерный сегмент.
4. MV3-совместимый блокировщик заведомо **хуже** старого — на качестве не выиграть.

### Пересчёт скоринга
| Критерий | Отчёт | Факт | Обоснование |
|---|---|---|---|
| Частота | 3 | 4 | боль подтверждена, вирусность высокая |
| Острота боли | 4 | 3 | реальна, но конвертируется в миграцию, а не в покупку |
| Платёжеспособность | 2 | 1 | ценовой якорь ~0, аудитория против платы |
| Конкуренция | 2 | 1 | uBO, Brave, AdGuard, Pi-hole, NextDNS — плотно и бесплатно |
| Реализуемость MVP | 3 | 3 | посильно, но MV3 ограничивает качество |
| Дистрибуция | 3 | 1 | платформенный риск Google, нет moat |
| **Σ** | **17** | **13** | **отклонить** |

### Единственный пивот
**Managed-DNS-фильтр для семей / SMB / школ** (родительский контроль, блок сервисов,
отчётность, per-device политики, encrypted DNS): продаётся не блокировка, а
managed-сервис + поддержка + compliance. По сути конкуренция с NextDNS/AdGuard в их
поле, но с нишевой вертикалью — оценка максимум ~16–18/30.

## Идея B: Приватная альтернатива GitHub (Σ 18 → 13)

### Проверка боли — реальна и свежа
GitHub в 2026 нестабилен: ~48 крупных сбоев за 12 месяцев, крупный инцидент
17.08.2026 (~20% ошибок), сбой Codespaces 12.02.2026. Знаковый отток: Митчелл
Хашимото увёл Ghostty с GitHub в апреле 2026. Но боль конвертируется в **миграцию
на уже существующие форджи**, а не в спрос на новый стартап.

### Конкуренты — поле забито, в т.ч. бесплатными и некоммерческими
- Self-host: Forgejo, Gitea, GitLab CE, Gogs — все бесплатны.
- Хостед: **Codeberg** (немецкий НКО на Forgejo, бесплатно), GitLab.com, SourceHut
  ($4–12/мес). «Приватная/некоммерческая альтернатива» уже реализована идейными
  игроками и бесплатно.

### Почему ниша неподъёмна для стартапа
1. **Капиталоёмкость.** Продаёшь «аптайм лучше GitHub» → жжёшь деньги на инфру/SRE
   годами; аргумент против GitHub требует именно того, что дорого стоит.
2. **Сетевой эффект Microsoft/GitHub** — граф идентичностей, звёзды, discovery,
   CI-экосистема — moat, который не берётся фичами.
3. **MVP = годы.** Полноценный форж (git + PR + CI/CD + issues + SSO + масштаб) —
   работа GitLab/Forgejo за 10+ лет. Форкнуть Forgejo = отдать дифференциацию апстриму.
4. **Против бесплатного не заработать** — идейный сегмент накрыт Codeberg/Forgejo.

Оценки бота (MVP 2/5, конкуренция 2/5) корректны — я бы поставил даже ниже.

### Пересчёт скоринга
| Критерий | Отчёт | Факт | Обоснование |
|---|---|---|---|
| Частота | 4 | 4 | сбои и отток реальны и свежи |
| Острота боли | 4 | 3 | реальна, но ведёт к миграции на готовое |
| Платёжеспособность | 3 | 2 | против бесплатных форджей + сетевой эффект |
| Конкуренция | 2 | 2 | GitLab, Forgejo, Gitea, Codeberg, SourceHut |
| Реализуемость MVP | 2 | 1 | полноценный форж = годы/капитал |
| Дистрибуция | 3 | 1 | moat у Microsoft, не у стартапа |
| **Σ** | **18** | **13** | **отклонить** |

### Единственный пивот (не «замена GitHub»)
Тонкий сервисный слой поверх git для регулируемых вертикалей: **managed/compliance-
форж** (air-gapped, on-prem, аудит, суверенность данных) для госсектора/оборонки/
медицины/финансов, либо **resilience-слой** (миграция/бэкап/зеркалирование между
форджами как страховка от даунтайма GitHub). Оба — сервисный B2B, не венчурный
«GitHub-killer».

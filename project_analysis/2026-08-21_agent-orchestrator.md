# Анализ идеи: Оркестратор ИИ-агентов для команд

- **Источник:** отчёт TrendScout, резерв (Σ = 19 в отчёте бота)
- **Дата анализа:** 2026-08-21
- **Вердикт:** ❌ **отклонить** горизонтальную идею — конкуренция лоб-в-лоб с
  владельцами моделей (Anthropic/OpenAI/Google/Cognition/YC), которые раздают
  ровно этот продукт бесплатно ради продажи токенов. Окно первого входа закрылось
  весной 2026. Возможен только узкий вертикальный governance-пивот.

## 1. Что утверждал отчёт

Мультиплеерный harness для работы, «CRM для агентов», роутинг задач. Триггеры —
`qm` (~14k ⭐) и `trycompai/crm` (~8.7k ⭐).

Масштаб звёзд обманчив: это свежий хайп с раздачей от YC, а не доказанный рынок.

## 3. Карта конкурентов (ниша перегрета до предела)

**Фреймворки-оркестраторы:** LangGraph/LangChain (де-факто дефолт 2026), CrewAI
(~2 млрд исполнений/год), Microsoft Agent Framework (ex-AutoGen), OpenAI Agents SDK,
**Anthropic Claude Agent SDK**, Google ADK + протокол A2A (150+ организаций),
Pydantic AI.

**No-code B2B:** n8n, Lindy ($50–200/мес), Relevance AI, Zapier, Make.

**Прямо «менеджер агентов для команд» уже выпустили гиганты (весна-лето 2026):**
Anthropic **Claude Code Agent Teams**, Cognition **Devin Desktop / Agent Command
Center**, Kilo Agent Manager, Conductor, Vibe Kanban, Cursor Background Agents.

Именно то, что предлагает идея, за последние 4 месяца выпустили Anthropic,
Cognition, YC и десяток others.

## 4. Барьеры для маленькой команды

1. **Конкуренция с владельцами моделей.** Anthropic/OpenAI/Google/Microsoft раздают
   оркестрацию **бесплатно** как часть SDK, чтобы продавать токены. Для них это
   loss-leader, для вас — весь бизнес. Ценой не выиграть.
2. **Категория «закрылась» на глазах** (Apr–Jun 2026 — конвергенция релизов). Окно
   первого входа закрыто; вы — 15-й.
3. **MVP 2/5 справедлив.** Демо собрать реально, но прод-grade мультиплеер
   (изоляция workspace, durable sandboxes, права, биллинг, аудит) — месяцы-годы,
   а планка задана бесплатным опенсорсом YC.
4. **Нет moat.** Стандарты (A2A, Agent Client Protocol) делают агентов
   взаимозаменяемыми — оркестратор становится тонкой прослойкой, поглощаемой платформой.

## 6. Условный пивот

Не горизонтальный оркестратор, а **вертикаль + governance-слой**, который гиганты
не делают: оркестрация агентов под конкретный регулируемый workflow (аудит
SOC2/HIPAA-действий агентов, cost-governance/бюджеты по отделам, human-in-the-loop
approval для не-инженерных функций — legal/accounting/ops). Это переводит идею из
«инфраструктуры агентов» (проигрышно) в «вертикальный SaaS с агентами» (менее
перегретый рынок) — по сути другая идея. Причём в compliance-угол уже целится Comp AI.

# Сравнение трёх пивотов: какой самый прибыльный

- **Дата:** 2026-08-21
- **Контекст:** после того как все 8 идей отчёта TrendScout отклонены, из разборов
  вышли три пивота в соседних (незакрытых) нишах. Здесь — детальный бизнес-разбор
  каждого и рекомендация.

  timing-play с быстрым входом. Обоснование ниже.

## 1. 🥇 Провенанс-комплаенс для EU AI Act — 21/30

**Почему первый:** единственный пивот, где сходятся *быстрый MVP* (2–4 недели поверх
бесплатного C2PA SDK, без ML) + *датированный триггер с крупным штрафом* + *платящий
B2B* + *чистые платежи*. Это классический regulatory-deadline timing-play.

**Рынок:** ст. 50 EU AI Act — видимая маркировка AI-контента с 02.08.2026,
машиночитаемая метка (то, что даёт C2PA) с 02.12.2026. Штраф до €15 млн / 3%
оборота. Глобальная волна: Испания (7% оборота), Китай (действует с 09.2025), 13+
штатов США. Обязаны и провайдеры ИИ, и деплойеры (бренды/медиа/агентства).

**Дифференциатор:** не «ещё один подписыватель» (c2patool бесплатен), а
**«Article 50 compliance-as-a-service»**: REST API, который отдаёт (a) машиночитаемый
C2PA-манифест, (b) корректный видимый дисклеймер, (c) audit-лог для регулятора.
Плюс batch-обработка, dashboard соответствия, managed-сертификат (абстрагировать
trust-list). Middle-market gap: между дорогим sales-led enterprise (Truepic/Digimarc)
и «сырым» бесплатным CLI никто не даёт удобный self-serve compliance-workflow.

**Монетизация:** Free/Dev воронка → Starter $49–99/мес → Pro $299–999/мес (референс:
Imatag Monitor €299/мес) → API overage $0.001–0.01/операция → Enterprise custom.
Нарратив «подписка дешевле, чем €15М штраф» хорошо конвертит.

**Главный риск:** нативная встройка — Cloudflare Images уже даёт one-click Content
Credentials (~20% веба), CMS/DAM/генераторы последуют. Ядро (подпись) —
коммодити. Поэтому это **timing-play, а не долгоживущий moat-бизнес**: быстрый
revenue на дедлайне + возможный acqui-hire/партнёрство. Вторичный риск —
enforcement ещё не начался, часть рынка тянет с покупкой.

**Валидация (1–2 дня):** лендинг «Article 50 Compliance API» + waitlist; 5–8 интервью
с агентствами/брендами ЕС о готовности к дедлайну и WTP; за пару часов прогнать
c2patool (подтвердить тривиальность обёртки); пройти онбординг Trufo/Truepic/
Cloudflare как клиент — зафиксировать gap. Go при ≥15–20 заявках + ≥3 явных «заплачу».

## 2. 🥈 Вертикальный IDP (страхование) — 19/30 (14 без домен-инсайдера)

**Почему второй:** самый защищённый бизнес (реальный moat) и самая высокая
платёжеспособность, но **не быстрый старт и не для команды без домен-эксперта/ML**.

**Выбор вертикали:** из трёх (финансы / страхование / юр) — **страхование**, узкий
класс (loss runs / ACORD-пакеты / COI). Юр отсеян (капитальная гонка: Harvey $1.22
млрд, идёт shakeout — Robin AI в банкротстве). Финансы плотнее и жёстче (Ocrolus
глубоко окопан в лендинге). Страхование выигрывает по формуле «острая боль ×
платёжеспособность × слабые incumbent'ы ($20М) × стандартизированная ACORD-схема
+ грязный long-tail, который generic закрывает плохо».

**Moat:** доменные данные (корпус грязных loss runs → data flywheel через HITL),
точность под схему с бизнес-правилами, compliance (audit trail, per-field
confidence, SOC2), интеграции (Guidewire/Duck Creek/AMS). Generic-парсеры уже дают
99% на *чистых* документах — ценность смещается в семантику, long-tail, SLA.

**Честная оговорка:** MVP = 3–5 месяцев (движок + review-UI + confidence + audit +
1 интеграция), нужна ML-компетенция, доменные данные (холодный старт болезненный),
HITL — операционный бизнес (давит маржу), длинный enterprise-цикл. **Оправдано
только при наличии инсайдера-домена** (бывший андеррайтер/брокер = доступ к данным
и первым пилотам). Без него ≈14/30.

**Монетизация:** $1–10/док (Ocrolus ~$5–10), платформа от ~$18K/год, enterprise
$50–250K+/год. Крупные чеки, но медленные.

**Валидация:** собрать 15–30 грязных loss runs, прогнать через LlamaParse/Reducto/
Azure — замерить, где ломаются (это ваша щель); 10 интервью с брокерами; fake-door
на платный пилот. Go при: generic заметно ломается + ≥2 клиента на пилот + доступ
к данным.

## 3. 🥉 Аудит безопасности dsh-плагинов — 18/30

**Почему третий (и почему пробел уже закрывается):** тайминг и исполнимость сильные,
но структурно хрупко. **Ключевое открытие разбора:** предполагавшийся пробел
(«никто не делает это специфично для DSH») уже закрыт — за ~неделю с запуска DSH
появилось 3+ бесплатных DSH-нативных сканера: `PerryLink/dsh-skill-pack-security`
(plugin_vet), `dsh-poison-guard`, `Darren-Tang/dsh-provenance`, плюс trust-registry
`dsh.so`. Идея входит в уже формирующуюся толпу, а не в пустую нишу.

**Боль:** категория доказана деньгами в соседних экосистемах (VSCode GlassWorm —
35k заражений; npm Shai-Hulud — 518М загрузок/мес; первый вредоносный MCP-сервер
postmark-mcp; OWASP MCP03 Tool Poisoning). Но **своего DSH-инцидента-якоря ещё нет** —
продать «страховку до пожара» трудно, бюджеты почти нулевые.

**Конкуренция:** движки коммодитизированы (Semgrep+Gitleaks бесплатны), горизонтальный
Socket.dev заходит в один клик за $25/dev и покрывает всё сразу, MCP-сегмент уже
показал и модель, и «verified»-бейдж (Docker MCP Catalog — нативные подписи/SBOM/
trust-levels).

**Монетизация:** единственный живой канал — **каталоги (B2B API, $300–1500/мес** за
trust-фид, модель валидирована Invariant mcp-scan), но каталоги сами бедны. Команды
($20–35/dev) конкурируют с бесплатными OSS-гейтами. Авторы (pay-for-badge) — слабейший
канал, риск «badge-mill».

**Главный риск:** DeepSeek встроит verified-реестр в официальный Plugin Center — для
179k-звёздного проекта вопрос месяцев (паттерн Docker/VSCode/Chrome). Тогда сторонний
бейдж обесценится. Плюс вся ставка на один продукт в dev-preview.

**Валидация:** написать 4–6 каталогам о готовности платить за trust-API + спросить,
не ждут ли официальный реестр от DeepSeek; прогнать 20–30 dsh-репо через
Gitleaks+Semgrep+JS-X-Ray — посчитать % находок. Go только при ценовом сигнале от
каталога И отсутствии сигнала о скором офиц. реестре.

## 4. Итоговая рекомендация

**Начать с провенанс-комплаенса (пивот №1)** — при условии, что цель — быстрая
выручка на регуляторном окне, а не построение защищённого на годы бизнеса:

- ✅ MVP за 2–4 недели без ML/домен-экспертизы — совпадает с ресурсами маленькой команды.
- ✅ Датированный триггер с крупным штрафом уже «на часах» (02.08 / 02.12.2026).
- ✅ Платящий B2B, чистые платежи, глобальный рынок (не только ЕС).
- ⚠️ Осознанно как timing-play: слабый moat, потолок из-за commodity-ядра и риска
  нативной встройки. Стратегия — быстрый вход, middle-market, продавать
  *compliance/audit*, а не *подпись*; выход через партнёрство/acqui-hire.

**IDP (№2)** держать как «план на вырост» — если в команде появится домен-инсайдер
из страхования, это самый защищённый и денежный путь, но не сейчас и не быстро.

**Аудит dsh-плагинов (№3)** — отклонить или переупаковать: пробел уже закрывается
бесплатными сканерами, рынок мал и висит на одном preview-продукте, вероятный исход —
поглощение платформой. Жизнеспособен максимум как узкий B2B trust-API для каталогов,
но upside низкий.

Все три оценки — при пороге отбора TrendScout 20/30 — формально проходит только
пивот №1.

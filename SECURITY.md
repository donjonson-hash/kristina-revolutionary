# 🔒 Security Guide - Kristina AI

## Быстрый старт

```bash
# 1. Скопируйте шаблон
cp .env.example .env

# 2. Отредактируйте .env (nano, vim, или любой редактор)
nano .env

# 3. Заполните реальными ключами
# 4. НИКОГДА не коммитьте .env!
```

## Критические правила

### ❌ Запрещено
- Коммитить `.env` в git
- Хранить ключи в коде (hardcode)
- Делиться ключами в мессенджерах
- Использовать один ключ для dev/prod

### ✅ Обязательно
- Использовать `.env.example` как шаблон
- Хранить ключи в менеджере паролей
- Использовать разные ключи для разных сред
- Регулярно ротировать ключи

## Проверка безопасности

```bash
# Проверить, не попали ли ключи в git
git log --all --full-history --source -S 'sk-' -- .env

# Поиск ключей в коде
grep -r "sk-[a-zA-Z0-9]\{20,\}" --include="*.py" .
```

## При компрометации

1. **Немедленно отзовите ключ** на сайте провайдера
2. Сгенерируйте новый ключ
3. Обновите `.env`
4. Перезапустите сервис
